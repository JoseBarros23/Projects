# Detector de Emociones en Tiempo Real / Real-Time Emotion Detector

## 🇪🇸 Descripción en Español

Este proyecto utiliza **[DeepFace](https://github.com/serengil/deepface)** y **OpenCV** para crear un detector de emociones en tiempo real a través de una cámara web. Detecta rostros y muestra la emoción dominante en pantalla.

### 📦 Requisitos

El archivo `requirements.txt` contiene las librerías necesarias con versiones que son **compatibles entre sí**.  
Se recomienda crear un **entorno virtual** o usar un **contenedor (como Docker)** para instalar estas dependencias de forma segura.

### ⚙️ Entorno de Ejecución

Todo el proyecto fue ejecutado en un **entorno virtual** de Python.

### 📁 Sobre el CSV en la carpeta

El archivo `emotion_log.csv` es un **ejemplo del resultado obtenido al correr la última parte del notebook**. Contiene un registro de las emociones detectadas junto con la marca de tiempo correspondiente.

---

## 🇬🇧 English Description

This project uses **[DeepFace](https://github.com/serengil/deepface)** and **OpenCV** to create a real-time emotion detector using a webcam. It detects faces and displays the dominant emotion on screen.

### 📦 Requirements

The `requirements.txt` file contains the required libraries with **compatible versions**.  
It's recommended to create a **virtual environment** or use a **container (like Docker)** to install and run the dependencies safely.

### ⚙️ Runtime Environment

The entire project was run inside a **Python virtual environment**.

### 📁 About the CSV in the folder

The file `emotion_log.csv` is an **example of the output generated by the final part of the notebook**. It contains a log of detected emotions along with their corresponding timestamps.
